# 5-Stage Pipelined RISC Processor Using Verilog HDL

## Project Overview
A 5-stage pipelined RISC processor designed using Verilog HDL and simulated using Xilinx Vivado.

## Architecture
The processor consists of five pipeline stages:

1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)

## Key Modules
- IF_ID
- ID_EX
- EX_MEM
- MEM_WB
- Instruction Memory
- Control Unit

## Tools & Technologies
- Verilog HDL
- Xilinx Vivado
- RTL Design
- Digital System Design

## Simulation
The processor simulation was successfully completed using Xilinx Vivado.
